# 08｜本地开发与部署

## 1. 前置要求

- Python 3.12+
- uv（依赖管理）
- 火山引擎 Ark API Key
- Tavily API Key（从 https://app.tavily.com 获取）
- 可选：高德开放平台 Key（https://lbs.amap.com，POI/交通）、和风天气 Key 与专属 API Host（https://dev.qweather.com，天气预报）

不需要 Node.js、前端或本地模型服务。LLM 使用云端 Ark API，搜索使用 Tavily Remote MCP + 高德 API。

## 2. 安装与启动 Web 应用

```bash
uv sync --extra dev
cp .env.example .env   # 填写 LLM_API_KEY、TAVILY_API_KEY（可选 AMAP_API_KEY / WEATHER_API_KEY）
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

访问 `http://127.0.0.1:8000/`。同一个 FastAPI 进程同时提供前端、API、SSE 和交付物文件。

## 3. CLI 调试入口（可选）

```bash
./start.sh
# 等价于：uv run python cli.py
```

开发时需要热重载可使用：

```bash
uv run uvicorn app.main:app --reload --port 8000
```

## 4. 检查与测试

```bash
UV_CACHE_DIR=/tmp/tripops-uv-cache uv run pytest -q --ignore=tests/test_comfyui.py  # 75 项
UV_CACHE_DIR=/tmp/tripops-uv-cache uv run ruff check app tests scripts cli.py
# 有 ComfyUI 环境时再运行全部：uv run pytest -q（78 项，其中 3 项需要外部服务）
```

`tests/conftest.py` 通过 autouse fixture 设置 `MOCK_MODEL_MODE=true`、`MOCK_IMAGEGEN=true`，测试不消耗真实 API 配额，也不依赖网络。`tests/test_comfyui.py` 标记为 `integration`，默认被跳过。

## 5. 环境变量

先复制示例文件：

```bash
cp .env.example .env
```

| 变量 | 用途 |
| --- | --- |
| `LLM_BASE_URL` | Ark API 地址（默认 `https://ark.cn-beijing.volces.com/api/coding/v3`） |
| `LLM_API_KEY` | Ark API Key（必填） |
| `LLM_MODEL` | 默认模型（`ark-code-latest`） |
| `LLM_MODEL_COMPLEX` | 复杂推理模型（默认 `DeepSeek-V4-Pro`） |
| `LLM_MODEL_SIMPLE` | 对话模型（默认 `Doubao-Seed-2.0-lite`） |
| `LLM_MODEL_MULTIMODAL` | 多模态模型（默认 `Doubao-Seed-2.1-turbo`） |
| `LLM_MAX_ATTEMPTS` | 模型结构化调用最大尝试次数（默认 2） |
| `MOCK_MODEL_MODE` | `true` 时 LLM 节点走确定性兜底（仅测试用） |
| `TAVILY_SEARCH_ENABLED` | 是否启用 Tavily 搜索 |
| `TAVILY_MCP_URL` | Tavily Remote MCP 地址 |
| `TAVILY_API_KEY` | Tavily API Key（必填） |
| `TAVILY_SEARCH_DEPTH` | 搜索深度（默认 `advanced`） |
| `TAVILY_SEARCH_TIMEOUT_SECONDS` | 搜索超时 |
| `AMAP_API_KEY` | 高德开放平台 Key（可选，开启 POI/真实交通） |
| `WEATHER_API_KEY` | 和风天气 Key/凭据（可选，行程编排参考天气） |
| `WEATHER_BASE_URL` | 和风天气专属 API Host（新版控制台必须配置，形如 `https://xxxx.re.qweatherapi.com/v7`） |
| `WEATHER_GEO_BASE_URL` | 可选的独立城市搜索 Host；留空时复用 `WEATHER_BASE_URL` |
| `MOCK_IMAGEGEN` | `true` 使用预处理海报素材，`false` 调用 ComfyUI |
| `IMAGEGEN_API_URL` | ComfyUI 端点 |
| `IMAGEGEN_QUEUE_TIMEOUT_SECONDS` | 等待 ComfyUI 排队的最大时间 |
| `IMAGEGEN_EXECUTION_TIMEOUT_SECONDS` | 单张图片实际执行的最大时间 |
| `IMAGEGEN_MAX_ATTEMPTS` | 单张图片最大尝试次数 |

不要提交真实密钥。`.env` 已加入 `.gitignore`。

## 6. Tavily MCP 真实搜索

在 Tavily 控制台创建 API Key，然后配置：

```env
TAVILY_SEARCH_ENABLED=true
TAVILY_MCP_URL=https://mcp.tavily.com/mcp
TAVILY_API_KEY=tvly-your-key
TAVILY_SEARCH_DEPTH=advanced
```

后端通过 MCP Streamable HTTP 调用远程 `tavily_search` Tool。未配置 API Key 时 `search_attractions` 会明确抛出 `MCPToolError`。详细实现参见 [11-Tavily-MCP真实搜索](./11-Tavily-MCP真实搜索.md)。

## 7. 高德地图（可选）

```env
AMAP_API_KEY=<amap-web-service-key>
```

启用后 `retrieve_resources` 增加高德 POI 检索，`plan_itinerary` 使用高德真实交通时长，高德天气还可作为和风天气的降级来源。高德单路失败会记录错误并继续尝试 Tavily；只有所有资源来源均无可用结果时才终止。

## 8. 天气服务（可选）

```env
WEATHER_API_KEY=<qweather-key>
WEATHER_BASE_URL=https://<控制台分配的Host>.re.qweatherapi.com/v7
```

> 注意：和风天气已于 2026 年起停用共享域名（`devapi.qweather.com` / `api.qweather.com`）。新版控制台为每个账号分配专属 **API Host**（控制台 → 设置中查看，形如 `https://xxxx.re.qweatherapi.com`），必须配置 `WEATHER_BASE_URL` 指向该 Host（含 `/v7` 路径），否则请求返回 403 `invalid-host`。凭据（API Key）在控制台 → 项目管理 → 凭据中创建。

本项目仅使用和风天气的两个服务（控制台 → 项目管理 → 项目 → 服务/API 权限中开启即可）：

| 服务 | 端点 | 用途 |
|---|---|---|
| 城市搜索 GeoAPI v2 | `GET /geo/v2/city/lookup` | 把城市名解析为经纬度 |
| 每日天气预报 v1 | `GET /weather/v1/daily/{latitude}/{longitude}` | 获取目的地 1-10 天逐日预报，注入行程编排 |

其余服务（实况、逐小时、分钟降水、空气质量、预警、天气指数、时光机、台风、海洋、太阳辐射、天文、控制台 API 等）本项目均不需要。

代码约定（`app/services/weather.py`）：
- 传入的城市名（如"杭州"）会先经 GeoAPI v2 解析为经纬度，再调用 v1 每日预报；直接传 `lng,lat` 则跳过解析。
- v1 每日预报支持 `days=1-10`，本实现取 `min(days, 10)` 原样透传；请求带 `localTime=true&lang=zh`，日期取本地时间。
- 鉴权沿用 API KEY（`key=` 查询参数），新版 v1 端点与 GeoAPI v2 均支持。

启用后 `plan_itinerary` 会获取逐日预报并注入行程 Prompt，同时写入报告。和风未配置或调用失败时，有 `AMAP_API_KEY` 会自动降级到高德天气；两者都不可用才终止。报告会依据 `provider` 标明实际来源。

## 9. 文生图服务（可选）

开发默认使用预处理素材：

```env
MOCK_IMAGEGEN=true
```

接入真实 ComfyUI 时：

1. 设置 `MOCK_IMAGEGEN=false`。
2. 配置 `IMAGEGEN_API_URL` 指向 ComfyUI 端点。
3. 确保 `app/services/comfyui/workflow_template.json` 与工作流节点匹配。

可以用 `scripts/test_comfyui_quick.py` 先做连通性验证。正式流程会顺序提交图片任务，适配性能一般的单 GPU 机器；ComfyUI 失败时尝试真实景点图片或高德静态地图。封面或任意一天图片仍缺失时会阻止审批，不会交付缺图 PDF。

## 10. Docker Compose

仓库提供 `Dockerfile` 与 `docker-compose.yml`，`api` 服务可直接构建运行：

```bash
docker compose up --build
```

- 默认执行 `uvicorn app.main:app`，挂载 `./data` 卷保存方案。
- 持久化使用 JSON 文件（`data/plans/`），不需要数据库服务。

## 11. 推荐开发顺序

1. 先运行 `uv run pytest -q -m "not integration"` 确认环境正常。
2. 配置 `.env`，启动 Web 应用完成一次真实对话策划。
3. 需要调试接口时使用 Swagger；策划仍必须从已确认的对话会话启动。
4. 依次接入高德地图和 ComfyUI。

## 12. 常见问题

### 审批 thread_id 无法恢复

当前使用内存 checkpoint。确认创建与审批请求命中同一个进程，并且进程没有重启。

### Tavily 搜索报错

检查 `TAVILY_API_KEY` 是否配置、网络是否可访问 `https://mcp.tavily.com/mcp`。未配置或调用失败抛 `MCPToolError`，工作流失败并在前端显示。

### LLM 返回无效 JSON

`ModelGateway` 注入字段描述、强制 `json_object`、清理代码围栏并做有限重试。若仍失败，聊天接口返回 JSON 502，SSE 返回结构化 error，前端会显示可读提示而不是 JSON 解析异常。

### 四日游只生成一天

该少资源特殊分支已修复：优化器始终返回请求天数的日槽，资源不足日会补为自由活动/休整。`validate_constraints` 与 `verifier.day_coverage` 会双重阻止缺天、重复天或超出天数的方案。

### 成本为 0 或 CostBreakdown 校验失败

LLM 的零金额项会在进入 `QuoteItem` 前过滤；全部为零时使用保守的非零成本明细。行程节点的 0 通过免费、已含、自理、待确认语义展示，不会渲染为 `¥0`。

### 高德 POI / 交通为空

确认 `AMAP_API_KEY` 已配置且 Key 类型为 Web 服务（不是 Web 端 JS Key），并已开通对应服务。
