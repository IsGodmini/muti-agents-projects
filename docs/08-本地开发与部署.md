# 08｜本地开发与部署

## 1. 前置要求

- Python 3.12+
- uv（依赖管理）
- 火山引擎 Ark API Key
- Tavily API Key（从 https://app.tavily.com 获取）

不需要 Node.js、前端或本地模型服务。LLM 使用云端 Ark API，搜索使用 Tavily Remote MCP。

## 2. 安装与启动

```bash
uv sync --extra dev
cp .env.example .env   # 填写 LLM_API_KEY 和 TAVILY_API_KEY
./start.sh
```

`start.sh` 会执行 `uv run python cli.py`，进入对话式策划界面。

## 3. 启动 REST API（可选）

```bash
uv run uvicorn app.main:app --reload --port 8000
```

访问：

- 健康检查：`http://localhost:8000/api/v1/health`
- Swagger：`http://localhost:8000/docs`

## 4. 检查与测试

```bash
uv run pytest -q
uv run ruff check app tests cli.py
```

测试使用 `MOCK_MODEL_MODE=true`（由 `tests/conftest.py` 自动设置），不消耗真实 API 配额。

## 5. 环境变量

先复制示例文件：

```bash
cp .env.example .env
```

| 变量 | 用途 |
| --- | --- |
| `LLM_BASE_URL` | Ark API 地址（默认 `https://ark.cn-beijing.volces.com/api/coding/v3`） |
| `LLM_API_KEY` | Ark API Key（必填） |
| `LLM_MODEL` | 模型名（默认 `ark-code-latest`） |
| `MOCK_IMAGEGEN` | `true` 使用预处理海报素材，`false` 调用 ComfyUI |
| `IMAGEGEN_API_URL` | ComfyUI 端点（默认 `http://127.0.0.1:8188`） |
| `MOCK_MODEL_MODE` | `true` 时 LLM 节点走确定性兜底（仅测试用） |
| `TAVILY_SEARCH_ENABLED` | 是否启用 Tavily 搜索 |
| `TAVILY_MCP_URL` | Tavily Remote MCP 地址 |
| `TAVILY_API_KEY` | Tavily API Key（必填） |
| `TAVILY_SEARCH_DEPTH` | 搜索深度（默认 `advanced`） |
| `TAVILY_SEARCH_TIMEOUT_SECONDS` | 搜索超时 |

不要提交真实密钥。`.env` 已加入 `.gitignore`。

## 6. Tavily MCP 真实搜索

在 Tavily 控制台创建 API Key，然后配置：

```env
TAVILY_SEARCH_ENABLED=true
TAVILY_MCP_URL=https://mcp.tavily.com/mcp
TAVILY_API_KEY=tvly-your-key
TAVILY_SEARCH_DEPTH=advanced
```

后端通过 MCP Streamable HTTP 调用远程 `tavily_search` Tool。未配置 API Key 时 `search_attractions` 会明确抛出异常，而不会静默降级到演示数据。详细实现参见 [11-Tavily-MCP真实搜索](./11-Tavily-MCP真实搜索.md)。

## 7. 文生图服务（可选）

开发默认使用预处理素材：

```env
MOCK_IMAGEGEN=true
```

接入真实 ComfyUI 时：

1. 设置 `MOCK_IMAGEGEN=false`。
2. 配置 `IMAGEGEN_API_URL` 指向 ComfyUI 端点。
3. 确保 `app/services/comfyui/workflow_template.json` 与工作流节点匹配。

海报失败不应让已经批准的行程数据丢失。

## 8. Docker Compose（规划）

仓库保留了 `docker-compose.yml` 和 `infra/postgres/init.sql`，用于后续接入 PostgreSQL/PostGIS/pgvector、Redis 和 MinIO。当前命令行演示不依赖这些服务，使用 JSON 文件持久化即可运行。

启用数据库时需要：

1. 更新 `docker-compose.yml` 中的路径以匹配当前项目结构。
2. 用持久化 LangGraph checkpoint 替换 `MemorySaver`。
3. 将 `PlanStore` 从文件切换到数据库。

## 9. 推荐开发顺序

1. 先运行 `uv run pytest -q` 确认环境正常。
2. 配置 `.env`，用 CLI 完成一次真实策划。
3. 需要调试时启动 REST API，用 Swagger 触发工作流。
4. 最后按需接入 ComfyUI 和数据库。

## 10. 常见问题

### 审批 thread_id 无法恢复

当前使用内存 checkpoint。确认创建与审批请求命中同一个进程，并且进程没有重启。

### Tavily 搜索报错

检查 `TAVILY_API_KEY` 是否配置、网络是否可访问 `https://mcp.tavily.com/mcp`。

### LLM 返回无效 JSON

`ModelGateway._extract_json` 会剥离 markdown 代码块。若仍失败，相关节点会降级或抛出异常，日志中可查看原始响应。
